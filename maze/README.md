
# 3D Maze Game

A simple 3D maze game built with Node.js for terminal. Navigate through the maze, collect items, and avoid walls.

## Controls:
- **W**: Move forward
- **S**: Move backward
- **A**: Rotate left
- **D**: Rotate right
- **Ctrl+C**: Exit

## How to Run:
1. Clone/download the source code.
2. Run the game with Node.js:
   ```
   node maze.js
   ```
3. Use the controls to play.

## Warning:
For proper game functionality, it is recommended to run the program in a full-screen terminal. The font size should be set to 3. If you change the values of screenWidth or screenHeight, you must also adjust the font size in the terminal to maintain the correct display proportions.

Enjoy the game!
